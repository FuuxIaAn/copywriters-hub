# 爆款标题 / 开篇钩子方法论

> 来源：小红书标题生成、小红书标题评分、微信爆款封面、文案骨架/爆款结构等技能的规律提炼。
> 适用：为口播稿设计标题、前 3 秒钩子、正文开篇时。

## 一、爆款标题通用规律（跨平台）

1. **短**：标题尽量控制在 20 字以内，越长点击越差。
2. **戳痛点/给利益**：直接点出目标人群的焦虑或想得到的好处，如"感情里总吃亏的人，多半没搞懂这一点"。
3. **制造悬念/反常识**：用反直觉的说法逼人点开，如"越努力越穷，是因为方向全错了"。
4. **具体数字**：用数字增加可信度和具体感，如"3 个判断你该不该分的信号"。
5. **身份代入**：让目标人群一眼觉得"这是说我"，如"20-30 岁女生，千万别踩这几个坑"。
6. **结果前置**：把最诱人的结果放前面，如"学会这个，一天看懂一个人的性格"。

## 二、标题公式模板（可直接套用）

- **痛点 + 解决方案**：`<痛苦场景>，<只差这一步>`
- **反常识 + 揭秘**：`原来<常识认知>，其实是错的`
- **数字清单**：`<N>个<主题>，<效果承诺>`
- **身份 + 忠告**：`<人群>，<少走弯路的一句话>`
- **提问式**：`为什么<普遍困惑>？答案很简单`

## 三、前 3 秒钩子（口播开篇）

1. **悬念型**：先抛出反常结果，再讲原因。
2. **利益型**：先承诺观众看完能得到什么。
3. **共情型**：先替观众说出他们心里的纠结/委屈（万古同悲型，替人说准不煽情）。
4. **猎奇型**：稀缺事实 + 可核验证据，引发好奇。

## 四、评分标准（生成后自检）

| 维度 | 好标题特征 | 差标题特征 |
|------|-----------|-----------|
| 主题匹配 | 一眼懂讲什么 | 泛泛而谈 |
| 利益清晰 | 明确给好处 | 无承诺 |
| 情绪唤醒 | 有好奇/共鸣 | 平淡 |
| 稀缺感知 | 有独特性 | 千篇一律 |
| 合规安全 | 不踩红线 | 绝对化/夸大 |

## 五、红线

1. 标题不能为搏眼球而**捏造事实**或夸大承诺（尤其玄学类：禁"必旺/包招桃花/保转运"等绝对化表述）。
2. 标题与正文必须一致，避免标题党导致高跳出、低完播。
