# 爆款选题判断方法论（四基因 / 8 维打分 / 传播锚点）

> 来源：爆款炼金师（ViralTopicMaster）12 条策划心法 + 爆款四基因 + 8 维打分卡提炼。
> 适用：判断一个选题/一篇原稿值不值得做、能不能爆。用于群聊选题讨论、洗稿前的素材价值判断、复盘时的归因参考。

## 一、爆款四基因（选题至少命中 2 条才值得做）

1. **情绪钩子**：能唤起好奇/共鸣/不平/惋惜等强烈情绪，情绪越浓传播力越强。
2. **信息差**：观众看完觉得「学到了别人不知道的」（命理冷知识、反常识规律）。
3. **身份标签**：目标人群（20-30 岁年轻女性）一眼觉得「这说的就是我」。
4. **行动触发**：看完想做点什么——对照自查、转发给闺蜜、评论区问自己的情况。

## 二、8 维打分卡（每项 1-5 分，总分 ≥30 合格，≥35 优质）

| 维度 | 打分要点 |
|------|---------|
| 情绪 | 情绪浓度：无感 1 分 → 看完想哭/想转 5 分 |
| 传播 | 有没有「转发给某个具体的人」的理由 |
| 独家 | 同题材里有没有别人没给过的角度 |
| 身份 | 目标人群的代入精准度 |
| 时效 | 蹭没蹭上当下热点/节气/社会情绪 |
| 传播锚点 | 有没有「截图即传播」的一页/一帧 |
| 可视化 | 能不能落到具体画面/场景，而非纯说理 |
| 门槛 | 3 秒内能懂在讲什么 |

**纪律：低于 30 分的选题直接放弃或重做方向，不硬写；打分必须给出每项的具体理由，不许凭感觉给分。**

## 三、传播锚点（每个终稿必须有）

- 定义：观众截一张图或截 15 秒，不用解释别人也能懂、也想转发的那个瞬间（一句金句、一个反差画面、一个对照表）。
- 检查：终稿里找不到可截图传播的锚点 = 打回重写锚点段。

## 四、判断纪律

1. 红线优先于爆款：玄学类禁绝对化承诺（详见合规红线档案），命理结论用「倾向/常见/多」表述。
2. 数据说话：判断选题优先看对标账号同类选题的真实赞数，不凭感觉。
3. 宁缺毋滥：低分选题明确说「不建议做」并给提分方向，不输出平庸方案。
